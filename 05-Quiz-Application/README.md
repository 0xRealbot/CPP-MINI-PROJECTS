
# 🧠 C++ Quiz Application

A simple C++ console-based quiz application that asks multiple-choice questions, checks answers, and calculates the final score.

## ✨ Features

- Multiple-choice questions
- Four options for every question
- Automatic answer checking
- Score calculation
- Final performance message
- Supports uppercase and lowercase answers

## 🛠️ Concepts Used

- Arrays
- Variables and data types
- Conditional statements (`if-else`)
- Loops and basic input/output
- Comparison operators
- Arithmetic operators

## 📂 Project Structure

```text

```

## ▶️ How to Run

Compile the program:

```bash
g++ main.cpp -o quiz
```

Run on Windows:

```powershell
.\quiz.exe
```
