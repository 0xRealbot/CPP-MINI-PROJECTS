
# 🎮 0xRealbot Number Guessing Game

A command-line number guessing game developed using C++.

The computer generates a random number between 1 and 100, and the player must guess it within a limited number of attempts.

## ✨ Features

- Random number generation (1–100)
- Three difficulty levels:
  - Easy: 10 attempts
  - Medium: 7 attempts
  - Hard: 5 attempts
- Higher and lower hints
- Attempt counter
- Winning and losing messages
- Replay option

## 🛠️ Concepts Used

- Variables and Data Types
- Conditional Statements
- Switch Statements
- While and Do-While Loops
- Random Number Generation
- Functions from C++ Standard Libraries
- Break and Continue

## ▶️ How to Run

Compile using GCC:

```bash
g++ main.cpp -o game
```

Run on Windows:

```powershell
.\game.exe
```

## 🎯 How to Play

1. Choose a difficulty level.
2. Enter a number between 1 and 100.
3. Follow the higher or lower hints.
4. Guess correctly before your attempts run out!
5. Choose whether to play again.
