
# 🏦 Banking Simulation

A simple C++ console-based banking application that simulates basic banking operations such as checking balance, depositing money, and withdrawing money.

## ✨ Features

- Check account balance
- Deposit money
- Withdraw money
- Prevent invalid deposit amounts
- Prevent withdrawals exceeding the available balance
- Menu-driven interface

## 🛠️ Concepts Used

- Variables and data types
- Conditional statements (`if-else`)
- Switch statements
- Loops (`do-while`)
- Arithmetic operators
- Input and output (`cin`, `cout`)

## ▶️ How to Run

Compile the program:

```bash
g++ main.cpp -o bank
```

Run on Windows:

```powershell
.\bank.exe
```

## 📸 Sample Menu

```text
===== BANKING SIMULATION =====
1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit

Enter your choice:
```
