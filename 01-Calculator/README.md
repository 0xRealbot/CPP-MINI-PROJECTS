
# 🧮 0xRealbot Calculator

A simple command-line calculator built using C++.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%)
- Division-by-zero protection
- Repeat calculations without restarting the program
- Invalid operator handling

## 🛠️ Concepts Used

- Variables and Data Types
- User Input and Output
- Switch Statements
- Do-While Loops
- If-Else Conditions
- Type Casting

## ▶️ How to Run

Compile using GCC:

```bash
g++ main.cpp -o calculator
```

Run:

```bash
./calculator
```

On Windows:

```bash
.\calculator.exe
```
