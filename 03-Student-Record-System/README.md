
# 🎓 Student Record Management System

A simple C++ console-based application to manage student information using structures, arrays, loops, and conditional statements.

## ✨ Features

- Add new student records
- Display all student records
- Search students using their ID
- Calculate average marks of all students
- Menu-driven interface
- Supports up to 50 students

## 🛠️ Concepts Used

- Structures (`struct`)
- Arrays
- Strings
- Loops (`do-while`, `for`)
- Conditional statements (`if-else`)
- Switch statements
- Input and output (`cin`, `cout`)
- Basic calculations

## ▶️ How to Run

Compile the program:

```bash
g++ main.cpp -o student
```

Run on Windows:

```bash
.\student.exe
```
